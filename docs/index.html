Если ничего не происходит

Файл скачивается целиком, но Android не показывает установку, пока браузеру, из которого вы качаете, не разрешено ставить приложения. Это ограничение Android 8 и новее, а не ошибка ссылки.

Huawei, Honor

Настройки → Безопасность → Установка приложений → выберите браузер → Разрешить

Остальные Android

Настройки → Приложения → Специальный доступ → Установка неизвестных приложений → ваш браузер → Разрешить

Если ссылка открылась внутри Telegram

  • Нажмите и держите кнопку «Скачать TurboBeeVPN» → «Открыть в браузере».
  • Разрешите установку тому браузеру, который откроется, и повторите скачивание.

Файл уже скачан, а установщик не открывается

  • Откройте приложение «Файлы» или «Загрузки» → папка Download → TurboBeeVPN.apk.

Как работают обновления

  • Обновления приложение берёт само, отдельная кнопка не нужна.
  • Версия и размер показываются здесь из манифеста канала, поэтому страница не может разойтись с тем, что реально выложено.
