# TurboBee VPN

VLESS VPN-клиент с Bee-оформлением. Простой и надёжный.

## Возможности

- Поддержка VLESS (ws/tcp, tls)
- Полноценный VPN-туннель (TUN) — весь трафик через VPN
- Маршрутизация RU-трафика напрямую (по желанию)
- Сворачиваемый список ключей
- Настройки: язык (RU/EN), тема (светлая/тёмная), скрытие IP
- Минималистичный интерфейс

## Установка

### Android

1. Скачайте [`TurboBeeVPN.apk`](https://github.com/whisa777/TurboBeeVPN/raw/main/TurboBeeVPN.apk)
2. Откройте файл и разрешите установку из неизвестных источников
3. Добавьте свой ключ через кнопку «+»

### Windows

1. Скачайте [`TurboBeeVPN.exe`](https://github.com/whisa777/TurboBeeVPN/raw/main/TurboBeeVPN.exe)
2. Запустите от имени администратора (VPN-туннель требует прав администратора)
3. Добавьте свой ключ через кнопку «+ Добавить ключ»

## Как получить ключ

VLESS-ссылка выглядит так:

```
vless://UUID@host:port?path=...&type=ws&security=tls#Имя
```

Вставьте ссылку в приложение — она добавится автоматически.
